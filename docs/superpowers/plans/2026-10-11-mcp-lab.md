# MCP Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a locally runnable interactive MCP protocol debugger: a real MCP host/client/server in Python (FastAPI) plus a React control panel that visualizes the real execution trace.

**Architecture:** A stdio MCP server subprocess (`mcp_server.py`) exposes deterministic tools. A `LabClient` wraps `mcp.Client` over a tapping transport that records raw JSON-RPC. A `Host` orchestrates scenarios, applies policy, and drives a deterministic simulated LLM. Every action emits `Event`s into a `Recorder`; a backend-held playback cursor releases them over SSE to the React UI.

**Tech Stack:** Python 3.12, `mcp==2.3.0`, FastAPI, uvicorn, sse-starlette, pydantic; React 19, TypeScript, Vite, `@xyflow/react`.

**Spec:** `docs/superpowers/specs/2026-10-11-mcp-lab-design.md` (section 13 amendments supersede earlier text).

## Global Constraints

- SDK `mcp==2.3.0`; spec `2026-07-28` is modern; `initialize` handshake eras (up to `2025-11-25`) are shown only as labeled `legacy`.
- **No `__init__.py` files anywhere** (user decision; Python namespace packages). **No tests, test dirs, or test dependencies** (user decision). Verification is manual (curl, browser).
- **Do not install anything.** The user creates `backend/.venv` and runs `pip install -r requirements.txt` and `npm install`. Executors must ask the user to do this when a run step needs it.
- No work in a `backend/app/` directory. Backend packages live directly in `backend/`; run all backend commands from `backend/`.
- Launcher is `backend/run.py` (not `server.py`, because `backend/server/` is a package). MCP server entry is `backend/mcp_server.py`.
- The frontend never defines tools or scenarios. The host never imports `tools/` or `server/`. The client has no tool registry.
- Tool definitions exist only in `backend/tools/catalog.py`.
- Real MCP events have `kind="real_mcp"` (or `"legacy"`); simulated LLM events `kind="simulated"`; host-internal `kind="host_internal"`. Playback delay is visual only.
- Do not commit unless the user asks. Do not add agents or tests.

## Review Focus

- Calling any API endpoint before connecting: must return a clear 409/4xx, never hang or crash. (Phase 2, Task 2.4)
- Starting a scenario while another is running, or reset during a run: old subprocess must die, no orphan processes, no duplicated events. (Phase 3, Task 3.3)
- Server subprocess crash or missing script mid-session: surfaced as a `transport` error with `reached_server` accurate, not a hang. (Phase 1 Task 1.5, Phase 4 Task 4.2)
- SSE reconnect or page reload: replay from event 0 for the current run without duplicates. (Phase 3 Task 3.2, Phase 5 Task 5.2)
- Unicode or oversized tool arguments (text over 200 chars, non-ASCII): validation failure shown as `invalid_arguments`, UTF-8 survives the JSON-RPC trip. (Phase 2 Task 2.1)

```python
from typing import Any, Callable

from events.model import Event, now


class Recorder:
    def __init__(self, run_id: str, scenario_id: str | None, on_emit: Callable[[], None] | None = None):
        self.run_id = run_id
        self.scenario_id = scenario_id
        self.events: list[Event] = []
        self.finished = False
        self._on_emit = on_emit

    def emit(self, component: str, operation: str, status: str, kind: str, message: str, **extra: Any) -> Event:
        seq = len(self.events) + 1
        event = Event(
            id=f"{self.run_id}-{seq:04d}",
            run_id=self.run_id,
            scenario_id=self.scenario_id,
            seq=seq,
            component=component,
            operation=operation,
            status=status,
            kind=kind,
            message=message,
            ts=now(),
            **extra,
        )
        self.events.append(event)
        if self._on_emit:
            self._on_emit()
        return event
```

```python
from typing import Literal

from pydantic import BaseModel


class CalcResult(BaseModel):
    result: float
    expression: str


def calculator(op: Literal["add", "subtract", "multiply", "divide"], a: float, b: float) -> CalcResult:
    """Apply an arithmetic operation to two numbers. Division by zero raises a tool execution error."""
    symbols = {"add": "+", "subtract": "-", "multiply": "*", "divide": "/"}
    if op == "add":
        value = a + b
    elif op == "subtract":
        value = a - b
    elif op == "multiply":
        value = a * b
    else:
        if b == 0:
            raise ValueError("Division by zero is not defined")
        value = a / b
    return CalcResult(result=value, expression=f"{a} {symbols[op]} {b}")


TOOL_FUNCTIONS = [calculator]


def register_tools(mcp, wrap=lambda fn: fn) -> None:
    """Register every handler on the given MCPServer. `wrap` lets the server add tracing."""
    for fn in TOOL_FUNCTIONS:
        mcp.tool()(wrap(fn))
```

```python
import functools
import json
import sys
import threading

from mcp.server.mcpserver import MCPServer

from tools.catalog import register_tools

PREFIX = "MCPLAB_EVENT "
_lock = threading.Lock()
_n = 0


def emit(op: str, **data) -> None:
    """Server-side event side channel: one JSON line on stderr. stdout is reserved for JSON-RPC."""
    global _n
    with _lock:
        _n += 1
        line = PREFIX + json.dumps({"n": _n, "op": op, **data}, default=str)
        print(line, file=sys.stderr, flush=True)


def traced(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        emit("handler_start", tool=fn.__name__, arguments=kwargs)
        try:
            result = fn(*args, **kwargs)
        except Exception as exc:
            emit("handler_failed", tool=fn.__name__, error_type=type(exc).__name__, detail=str(exc))
            raise
        emit("handler_end", tool=fn.__name__)
        return result

    return wrapper


class TracedMCPServer(MCPServer):
    async def call_tool(self, name, arguments, *args, **kwargs):
        emit("received", tool=name, arguments=arguments)
        try:
            result = await super().call_tool(name, arguments, *args, **kwargs)
        except Exception as exc:
            emit("failed", tool=name, error_type=type(exc).__name__, detail=str(exc)[:300])
            raise
        emit("completed", tool=name)
        return result


def build_server() -> TracedMCPServer:
    server = TracedMCPServer("mcp-lab-server")
    register_tools(server, wrap=traced)
    return server
```

```python
from typing import Callable

from mcp.client.stdio import StdioServerParameters, stdio_client
from mcp.shared.message import SessionMessage

OnMessage = Callable[[str, SessionMessage], None]


class _TapRead:
    def __init__(self, inner, on_message: OnMessage):
        self._inner, self._cb = inner, on_message

    def _seen(self, item):
        if isinstance(item, SessionMessage):
            self._cb("<-", item)
        return item

    async def receive(self):
        return self._seen(await self._inner.receive())

    async def aclose(self):
        await self._inner.aclose()

    def __aiter__(self):
        return self

    async def __anext__(self):
        return self._seen(await self._inner.__anext__())

    async def __aenter__(self):
        return self

    async def __aexit__(self, *exc):
        await self._inner.aclose()


class _TapWrite:
    def __init__(self, inner, on_message: OnMessage):
        self._inner, self._cb = inner, on_message

    async def send(self, item, /):
        self._cb("->", item)
        await self._inner.send(item)

    async def aclose(self):
        await self._inner.aclose()

    async def __aenter__(self):
        return self

    async def __aexit__(self, *exc):
        await self._inner.aclose()


class TapTransport:
    """Wraps the SDK stdio transport and reports every JSON-RPC message in both directions."""

    def __init__(self, params: StdioServerParameters, errlog, on_message: OnMessage):
        self._cm = stdio_client(params, errlog=errlog)
        self._on_message = on_message

    async def __aenter__(self):
        read, write = await self._cm.__aenter__()
        return _TapRead(read, self._on_message), _TapWrite(write, self._on_message)

    async def __aexit__(self, *exc):
        return await self._cm.__aexit__(*exc)
```

```python
import json
import os
import threading
import time

from server.build import PREFIX

TERMINAL_OPS = {"completed", "failed"}


class StderrPump:
    """Owns the pipe wired to the server's stderr; parses MCPLAB_EVENT lines on a reader thread."""

    def __init__(self):
        read_fd, write_fd = os.pipe()
        self.write_file = os.fdopen(write_fd, "w")
        self._read_file = os.fdopen(read_fd, "r", errors="replace")
        self._cond = threading.Condition()
        self._events: list[dict] = []
        self.other_lines: list[str] = []
        threading.Thread(target=self._run, daemon=True).start()

    def _run(self) -> None:
        for line in self._read_file:
            line = line.rstrip("\n")
            with self._cond:
                if line.startswith(PREFIX):
                    try:
                        self._events.append(json.loads(line[len(PREFIX):]))
                    except json.JSONDecodeError:
                        self.other_lines.append(line)
                else:
                    self.other_lines.append(line)
                self._cond.notify_all()

    def drain(self, expected_terminal: int, timeout: float = 3.0) -> tuple[list[dict], bool]:
        """Block until `expected_terminal` completed/failed events arrived (or timeout); return and clear all."""
        deadline = time.monotonic() + timeout
        with self._cond:
            while sum(1 for e in self._events if e["op"] in TERMINAL_OPS) < expected_terminal:
                left = deadline - time.monotonic()
                if left <= 0:
                    break
                self._cond.wait(left)
            events = sorted(self._events, key=lambda e: e["n"])
            complete = sum(1 for e in events if e["op"] in TERMINAL_OPS) >= expected_terminal
            self._events = []
            return events, complete

    def settle(self, seconds: float = 0.2) -> None:
        """Short grace period so diagnostic stderr text from a dying process is captured."""
        time.sleep(seconds)

    def close(self) -> None:
        try:
            self.write_file.close()
        except OSError:
            pass
```

- [ ] **Step 1: Write `backend/client/lab_client.py`**

```python
import asyncio
import json
import sys
import time
from pathlib import Path
from typing import Any

from mcp import Client, Implementation, MCPError, StdioServerParameters

from events.model import ErrorInfo
from events.recorder import Recorder
from transports.stdio import StderrPump
from transports.tap import TapTransport

BACKEND_DIR = Path(__file__).resolve().parents[1]
CONNECTION_CLOSED = -32000  # observed: MCPError(-32000, "Connection closed") when the server process dies
PROTOCOL_CATEGORIES = {
    -32700: "parse_error",
    -32600: "invalid_request",
    -32601: "method_not_found",
    -32602: "invalid_params",
    -32603: "internal_error",
}


class ClientError(Exception):
    """Raised for transport-level failures (spawn failure, connection closed, not connected)."""


def dump(obj: Any) -> Any:
    return obj.model_dump(by_alias=True, exclude_none=True, mode="json") if hasattr(obj, "model_dump") else obj


def classify_tool_error(text: str, server_events: list[dict]) -> str:
    if any(e["op"] == "handler_start" for e in server_events):
        return "tool_exception"
    if text.startswith("Unknown tool"):
        return "unknown_tool"
    if "validation error" in text or "rejected arguments" in text:
        return "invalid_arguments"
    return "tool_error"  # SDK text heuristics; pinned to mcp==2.3.0


class LabClient:
    def __init__(self, recorder: Recorder, server_script: str | None = None):
        self.rec = recorder
        self.script = server_script or str(BACKEND_DIR / "mcp_server.py")
        self.connected = False
        self.mode: str | None = None
        self.protocol_version: str | None = None
        self.tools: list[dict] | None = None
        self._task: asyncio.Task | None = None
        self._queue: asyncio.Queue = asyncio.Queue()
        self._pump: StderrPump | None = None
        self._wire: list[tuple[str, dict, float]] = []
        self._sent_at: dict[Any, float] = {}
        self._req_method: dict[Any, str] = {}

    # ---- wire capture -------------------------------------------------
    def _on_wire(self, direction: str, session_message) -> None:
        msg = dump(session_message.message)
        now = time.perf_counter()
        if direction == "->" and "id" in msg and "method" in msg:
            self._sent_at[msg["id"]] = now
            self._req_method[msg["id"]] = msg["method"]
        self._wire.append((direction, msg, now))

    def _emit_message(self, direction: str, msg: dict, now: float) -> None:
        method = msg.get("method") or self._req_method.get(msg.get("id"))
        legacy = self.mode == "legacy" and method in ("initialize", "notifications/initialized")
        kind = "legacy" if legacy else "real_mcp"
        arrow = "client → server" if direction == "->" else "server → client"
        if "method" in msg and "id" in msg:
            self.rec.emit("transport", "jsonrpc_request", "started", kind,
                          f"JSON-RPC request {method} (id={msg['id']}) {arrow}",
                          direction="request", method=method, request=msg)
        elif "method" in msg:
            self.rec.emit("transport", "jsonrpc_notification", "completed", kind,
                          f"JSON-RPC notification {method} {arrow}",
                          direction="notification", method=method, request=msg)
        else:
            failed = "error" in msg
            latency = None
            if msg.get("id") in self._sent_at:
                latency = (now - self._sent_at[msg["id"]]) * 1000
            error = None
            if failed:
                code = msg["error"].get("code")
                error = ErrorInfo(layer="protocol", category=PROTOCOL_CATEGORIES.get(code, "protocol_error"),
                                  code=code, message=str(msg["error"].get("message")), reached_server=True)
            self.rec.emit("transport", "jsonrpc_response", "failed" if failed else "completed", kind,
                          f"JSON-RPC {'error' if failed else 'result'} for {method} (id={msg.get('id')}) {arrow}",
                          direction="response", method=method, response=msg, latency_ms=latency, error=error)

    def _emit_server_event(self, ev: dict) -> None:
        op, tool = ev["op"], ev.get("tool")
        table = {
            "received": ("server", "tools/call received", "started"),
            "completed": ("server", "tools/call returned", "completed"),
            "failed": ("server", "tools/call raised", "failed"),
            "handler_start": ("tool", f"{tool} handler start", "started"),
            "handler_end": ("tool", f"{tool} handler end", "completed"),
            "handler_failed": ("tool", f"{tool} handler raised", "failed"),
        }
        component, operation, status = table[op]
        self.rec.emit(component, operation, status, "real_mcp",
                      f"Server-side event '{op}' for tool '{tool}' (reported by the server over its stderr side channel)",
                      direction="internal", method="tools/call", data=ev)

    def _flush(self, server_events: list[dict] | None = None) -> None:
        """Emit buffered wire messages. With server events: requests, server events, then responses."""
        wire, self._wire = self._wire, []
        if server_events is None:
            for d, msg, now in wire:
                self._emit_message(d, msg, now)
            return
        for d, msg, now in wire:
            if d == "->":
                self._emit_message(d, msg, now)
        for ev in server_events:
            self._emit_server_event(ev)
        for d, msg, now in wire:
            if d == "<-":
                self._emit_message(d, msg, now)

    # ---- session task (owns the anyio context so it is entered/exited in one task) ----
    async def _session(self, mode: str, script: str, ready: asyncio.Future) -> None:
        self._pump = StderrPump()
        params = StdioServerParameters(command=sys.executable, args=[script], cwd=str(BACKEND_DIR))
        transport = TapTransport(params, self._pump.write_file, self._on_wire)
        try:
            async with Client(transport, mode=mode,
                              client_info=Implementation(name="mcp-lab-client", version="0.1.0")) as client:
                self.protocol_version = client.protocol_version
                ready.set_result(client)
                while True:
                    item = await self._queue.get()
                    if item is None:
                        return
                    fn, fut = item
                    try:
                        fut.set_result(await fn(client))
                    except Exception as exc:  # noqa: BLE001 - forwarded to the caller
                        fut.set_exception(exc)
        except Exception as exc:  # noqa: BLE001
            if not ready.done():
                ready.set_exception(exc)
        finally:
            self.connected = False
            self._pump.close()

    async def _run(self, fn):
        if not self.connected or self._task is None or self._task.done():
            raise ClientError("Not connected: the MCP session is not open (connect first).")
        fut = asyncio.get_running_loop().create_future()
        await self._queue.put((fn, fut))
        return await fut

    def _transport_error(self, operation: str, method: str | None, exc: BaseException, reached: bool) -> ClientError:
        text = f"{type(exc).__name__}: {exc}"
        stderr_tail = " | ".join(self._pump.other_lines[-3:]) if self._pump else ""
        if stderr_tail:
            text += f" (server stderr: {stderr_tail})"
        error = ErrorInfo(layer="transport", category="connection_failed", message=text, reached_server=reached)
        self.rec.emit("transport", operation, "failed", "real_mcp", f"Transport failure: {text}",
                      method=method, error=error)
        self.rec.emit("client", operation, "failed", "real_mcp", "Client could not complete the operation",
                      method=method, error=error)
        return ClientError(text)

    # ---- public operations ---------------------------------------------
    async def connect(self, mode: str = "auto", script: str | None = None) -> dict:
        if self.connected:
            raise ClientError("Already connected.")
        self.mode = mode
        script = script or self.script
        self.rec.emit("client", "connect", "started", "legacy" if mode == "legacy" else "real_mcp",
                      f"Opening stdio transport (mode={mode}): spawning the server subprocess and negotiating",
                      data={"mode": mode, "transport": "stdio", "command": [sys.executable, script]})
        ready = asyncio.get_running_loop().create_future()
        self._task = asyncio.create_task(self._session(mode, script, ready))
        try:
            client = await ready
        except BaseException as exc:  # includes ExceptionGroup from the SDK task group
            if self._pump:
                await asyncio.to_thread(self._pump.settle)
            self._flush()
            raise self._transport_error("connect", None, exc, reached=False) from None
        self.connected = True
        self._flush()
        info = {
            "protocol_version": client.protocol_version,
            "server_info": dump(client.server_info),
            "server_capabilities": dump(client.server_capabilities),
        }
        self.rec.emit("client", "connect", "completed", "legacy" if mode == "legacy" else "real_mcp",
                      f"Connected; negotiated protocol version {client.protocol_version}", data=info)
        return info

    async def call_tool(self, name: str, arguments: dict[str, Any]) -> dict:
        self.rec.emit("client", "call_tool", "started", "real_mcp", f"Issuing tools/call for '{name}'",
                      method="tools/call", data={"name": name, "arguments": arguments})
        try:
            result = await self._run(lambda c: c.call_tool(name, arguments))
            protocol_error = None
        except MCPError as exc:
            if exc.code == CONNECTION_CLOSED:
                self._flush()
                raise self._transport_error("call_tool", "tools/call", exc, reached=True) from None
            result, protocol_error = None, exc
        server_events, complete = await asyncio.to_thread(self._pump.drain, 0 if protocol_error else 1)
        self._flush(server_events)
        if not complete and not protocol_error:
            self.rec.emit("client", "server_events_incomplete", "completed", "host_internal",
                          "Server-side events did not all arrive before the timeout; trace may be missing server events")
        if protocol_error:
            error = ErrorInfo(layer="protocol", category=PROTOCOL_CATEGORIES.get(protocol_error.code, "protocol_error"),
                              code=protocol_error.code, message=protocol_error.message, reached_server=True)
            self.rec.emit("client", "call_tool", "failed", "real_mcp", "Server answered with a JSON-RPC error",
                          method="tools/call", error=error)
            return {"outcome": "protocol_error", "code": protocol_error.code, "message": protocol_error.message}
        raw = dump(result)
        text = " ".join(c.get("text", "") for c in raw.get("content", []) if c.get("type") == "text")
        is_error = bool(raw.get("isError"))
        category = classify_tool_error(text, server_events) if is_error else None
        error = None
        if is_error:
            error = ErrorInfo(layer="tool", category=category, message=text[:300], reached_server=True)
        self.rec.emit("client", "call_tool", "failed" if is_error else "completed", "real_mcp",
                      "Result delivered to the client" + (f" with isError=true ({category})" if is_error else ""),
                      method="tools/call", data={"result": raw}, error=error)
        return {"outcome": "result", "is_error": is_error, "category": category, "text": text,
                "structured": raw.get("structuredContent"), "result": raw}

    async def close(self) -> None:
        if self._task and not self._task.done():
            await self._queue.put(None)
            try:
                await asyncio.wait_for(self._task, timeout=5)
            except (asyncio.TimeoutError, Exception):  # noqa: BLE001
                self._task.cancel()
        self.connected = False
```

```python
_notes: list[Note] = [
    Note(id=1, title="MCP basics", body="Hosts own clients; clients talk to servers."),
    Note(id=2, title="Transports", body="stdio for local use, Streamable HTTP for remote."),
]


def calculator(op: Literal["add", "subtract", "multiply", "divide"], a: float, b: float) -> CalcResult:
    """Apply an arithmetic operation to two numbers. Division by zero raises a tool execution error."""
    symbols = {"add": "+", "subtract": "-", "multiply": "*", "divide": "/"}
    if op == "add":
        value = a + b
    elif op == "subtract":
        value = a - b
    elif op == "multiply":
        value = a * b
    else:
        if b == 0:
            raise ValueError("Division by zero is not defined")
        value = a / b
    return CalcResult(result=value, expression=f"{a} {symbols[op]} {b}")


def text_stats(text: Annotated[str, Field(max_length=200)]) -> TextStats:
    """Count characters, words and lines in a text of at most 200 characters."""
    return TextStats(characters=len(text), words=len(text.split()), lines=len(text.splitlines()) or 1)


def notes_add(
    title: Annotated[str, Field(min_length=1, max_length=60)],
    body: Annotated[str, Field(max_length=200)],
) -> Note:
    """Add a note to the in-memory store and return it. State persists until the session is reset."""
    note = Note(id=max((n.id for n in _notes), default=0) + 1, title=title, body=body)
    _notes.append(note)
    return note


def notes_list() -> NoteList:
    """List all notes in the in-memory store."""
    return NoteList(notes=list(_notes))


def notes_get(note_id: int) -> NoteLookup:
    """Look up a note by id. A missing note is a normal result with found=false, not an error."""
    for note in _notes:
        if note.id == note_id:
            return NoteLookup(found=True, note=note)
    return NoteLookup(found=False)

    """Always raises, to demonstrate a tool execution error."""
    raise RuntimeError("This tool always fails on purpose")
```

```python
from scenarios.models import PolicyConfig


@dataclass
class Verdict:
    allowed: bool
    reason: str = ""


class Policy:
    def __init__(self, cfg: PolicyConfig | None = None):
        self.cfg = cfg or PolicyConfig()

    def check(self, tool: str, arguments: dict, catalog_names: set[str]) -> Verdict:
        if tool in self.cfg.denied_tools:
            return Verdict(False, f"tool '{tool}' is on the host deny list")
        if self.cfg.enforce_catalog and tool not in catalog_names:
            return Verdict(False, f"tool '{tool}' is not in the discovered catalog")
        limit = self.cfg.max_abs_number
        if limit is not None:
            for key, value in arguments.items():
                if isinstance(value, (int, float)) and not isinstance(value, bool) and abs(value) > limit:
                    return Verdict(False, f"argument '{key}'={value} exceeds the host limit of {limit}")
        return Verdict(True)
```

```python
import asyncio

from events.recorder import Recorder


class Run:
    """A run's real events plus a playback cursor. Pacing is visual only; events are already recorded."""

    def __init__(self, run_id: str, scenario_id: str | None, delay_ms: int, paused: bool):
        self.run_id, self.scenario_id = run_id, scenario_id
        self.delay_ms, self.paused = delay_ms, paused
        self.cursor = 0
        self.closed = False
        self._tick = asyncio.Event()
        self._waiters: list[asyncio.Future] = []
        self.recorder = Recorder(run_id, scenario_id, on_emit=self._tick.set)
        self._player = asyncio.create_task(self._play())

    def _wake(self) -> None:
        for fut in self._waiters:
            if not fut.done():
                fut.set_result(None)
        self._waiters.clear()

    def _release(self, n: int = 1) -> None:
        self.cursor = min(self.cursor + n, len(self.recorder.events))
        self._wake()

    async def _play(self) -> None:
        while not self.closed:
            if not self.paused and self.cursor < len(self.recorder.events):
                self._release()
                await asyncio.sleep(self.delay_ms / 1000 if self.delay_ms else 0)
            else:
                self._tick.clear()
                if self.closed or (not self.paused and self.cursor < len(self.recorder.events)):
                    continue
                await self._tick.wait()

    def poke(self) -> None:
        self._tick.set()
        self._wake()

    def step(self) -> None:
        self._release(1)
        self._tick.set()

    def pause(self) -> None:
        self.paused = True
        self.poke()

    def resume(self) -> None:
        self.paused = False
        self.poke()

    def set_delay(self, ms: int) -> None:
        self.delay_ms = max(0, ms)
        self.poke()

    def close(self) -> None:
        self.closed = True
        self._tick.set()
        self._wake()

    async def released_events(self, start: int = 0):
        i = start
        while True:
            while i < self.cursor:
                yield self.recorder.events[i]
                i += 1
            if self.closed:
                return
            fut = asyncio.get_running_loop().create_future()
            self._waiters.append(fut)
            await fut

    def state(self) -> dict:
        total = len(self.recorder.events)
        if not self.recorder.finished:
            status = "running" if self.scenario_id else "idle"
        else:
            status = "complete" if self.cursor >= total else "finished"
        return {"run_id": self.run_id, "scenario_id": self.scenario_id, "status": status, "total": total,
                "released": self.cursor, "paused": self.paused, "delay_ms": self.delay_ms}
```

```python
        self.run: Run | None = None
        self.client: LabClient | None = None

        self._task: asyncio.Task | None = None

    async def _teardown(self) -> None:
        if self._task and not self._task.done():
            self._task.cancel()

        if self.client:

        self._counter += 1

        self.host = Host(self.client, SimulatedLLM(), self.run.recorder)
```

```python
from dataclasses import dataclass

from scenarios.models import Step


@dataclass
class Decision:
    tool: str
    arguments: dict
    rationale: str
    input_payload: dict
    output_payload: dict


class SimulatedLLM:
    """Deterministic scripted stand-in for a model. It sees the REAL discovered tool metadata."""

    def propose(self, user_message: str, step: Step, tools: list[dict]) -> Decision:
        catalog = [{"name": t["name"], "description": t.get("description"), "inputSchema": t.get("inputSchema")}
                   for t in tools]
        in_catalog = step.tool in {t["name"] for t in tools}
        arguments = step.arguments or {}
        return Decision(
            tool=step.tool or "",
            arguments=arguments,
            rationale=(f"Scripted by the scenario: call '{step.tool}'. "
                       f"That tool {'is' if in_catalog else 'is NOT'} in the catalog the host supplied."),
            input_payload={"user_message": user_message, "available_tools": catalog},
            output_payload={"type": "tool_use", "name": step.tool, "arguments": arguments},
        )

    def interpret(self, summary: str) -> dict:
        return {"input": {"tool_result_summary": summary},
                "output": {"type": "text", "text": f"Noted the tool outcome: {summary}"}}

    def final(self, template: str | None, summary: str) -> dict:
        text = (template or "{summary}").replace("{summary}", summary)
        return {"input": {"last_outcome": summary}, "output": {"type": "text", "text": text}}
```

```python
    async def send_raw(self, method: str, params: dict | None = None, with_envelope: bool = True) -> dict:
        """Send a deliberately raw JSON-RPC request. Uses the SDK dispatcher (private API: session._dispatcher)."""
        params = dict(params or {})
        if with_envelope and self.protocol_version in MODERN_PROTOCOL_VERSIONS:
            params["_meta"] = {"io.modelcontextprotocol/protocolVersion": self.protocol_version,
                               "io.modelcontextprotocol/clientCapabilities": {}}
        self.rec.emit("client", "raw_request", "started", "real_mcp",
                      f"Sending a raw '{method}' request via the SDK dispatcher (envelope {'included' if with_envelope else 'omitted'})",
                      method=method, data={"params": params})
        try:
            result = await self._run(lambda c: c.session._dispatcher.send_raw_request(method, params))
            protocol_error = None
        except MCPError as exc:
            if exc.code == CONNECTION_CLOSED:
                self._flush()
                raise self._transport_error("raw_request", method, exc, reached=True) from None
            result, protocol_error = None, exc
        self._flush([])  # empty list: requests first, then responses, no server events expected
        if protocol_error:
            error = ErrorInfo(layer="protocol", category=PROTOCOL_CATEGORIES.get(protocol_error.code, "protocol_error"),
                              code=protocol_error.code, message=protocol_error.message, reached_server=True)
            self.rec.emit("client", "raw_request", "failed", "real_mcp", "Server answered with a JSON-RPC error",
                          method=method, error=error)
            return {"outcome": "protocol_error", "code": protocol_error.code, "message": protocol_error.message}
        self.rec.emit("client", "raw_request", "completed", "real_mcp", "Server answered with a JSON-RPC result",
                      method=method, data={"result": result})
        return {"outcome": "result", "is_error": False, "category": None, "text": "", "structured": result,
                "result": result}
```

```python
    async def raw_request(self, method: str, params: dict | None = None, with_envelope: bool = True) -> dict:
        self.rec.emit("host", "dispatch_to_client", "started", "host_internal",
                      f"Host asks the client to send a raw '{method}' request (debug path, no LLM involved)")
        outcome = await self.client.send_raw(method, params, with_envelope)
        failed = outcome["outcome"] == "protocol_error"
        self.rec.emit("host", "receive_result", "failed" if failed else "completed", "host_internal",
                      "Host received: " + summarize(outcome)[:200], data=outcome)
        return outcome

    async def run(self, scenario) -> None:
        rec = self.rec
        policy = Policy(scenario.policy)
        summary, final_text = "", None
        rec.emit("user", "user_request", "completed", "host_internal", scenario.user_message,
                 data={"scenario_id": scenario.id, "title": scenario.title})
        rec.emit("host", "receive_request", "completed", "host_internal",
                 "Host received the request and loaded the scenario plan",
                 data={"steps": [s.type for s in scenario.steps], "policy": scenario.policy.model_dump()})
        try:
            for i, step in enumerate(scenario.steps, 1):
                rec.emit("host", "plan_step", "completed", "host_internal",
                         f"Step {i}/{len(scenario.steps)}: {step.type} (decided by the scenario configuration)",
                         data=step.model_dump(exclude_none=True))
                if step.type == "connect":
                    await self.connect(step.mode or "auto", step.script)
                elif step.type == "discover":
                    await self.discover()
                elif step.type == "raw_request":
                    summary = summarize(await self.raw_request(step.method, step.params, step.with_envelope))
                elif step.type == "propose_and_call":
                    if self.tools is None:
                        rec.emit("host", "auto_discover", "completed", "host_internal",
                                 "No catalog yet; the host discovers tools before consulting the LLM")
                        await self.discover()
                    rec.emit("host", "supply_tools_to_llm", "completed", "host_internal",
                             f"Host passes {len(self.tools)} discovered tool definitions to the simulated LLM",
                             data={"tool_names": [t["name"] for t in self.tools]})
                    decision = self.llm.propose(scenario.user_message, step, self.tools)
                    rec.emit("llm", "llm_input", "completed", "simulated",
                             "SIMULATED inference input: user message plus the real discovered tool definitions",
                             direction="request", data=decision.input_payload)
                    rec.emit("llm", "llm_output", "completed", "simulated",
                             "SIMULATED inference output (scripted tool-call proposal). " + decision.rationale,
                             direction="response", data=decision.output_payload)
                    outcome = await self.invoke(decision.tool, decision.arguments, policy)
                    summary = summarize(outcome)
                    interp = self.llm.interpret(summary)
                    rec.emit("llm", "llm_input", "completed", "simulated",
                             "SIMULATED inference input: the host's tool result", direction="request", data=interp["input"])
                    rec.emit("llm", "llm_output", "completed", "simulated",
                             "SIMULATED inference output (scripted)", direction="response", data=interp["output"])
                elif step.type == "final":
                    out = self.llm.final(step.template, summary)
                    rec.emit("llm", "llm_output", "completed", "simulated",
                             "SIMULATED final response (scripted template)", direction="response", data=out["output"])
                    final_text = out["output"]["text"]
                    rec.emit("host", "final_response", "completed", "host_internal",
                             "Host produced the final response", data={"text": final_text})
            rec.emit("host", "run_complete", "completed", "host_internal", "Scenario finished",
                     data={"final_response": final_text})
        except ClientError as exc:
            rec.emit("host", "run_complete", "failed", "host_internal", f"Run aborted: {exc}",
                     error=ErrorInfo(layer="transport", category="run_aborted", message=str(exc), reached_server=False))
        except Exception as exc:  # noqa: BLE001
            rec.emit("host", "run_complete", "failed", "host_internal", f"Run aborted by an unexpected error: {exc}",
                     error=ErrorInfo(layer="host", category="unexpected_error", message=str(exc), reached_server=False))
```

```ts
import { useEffect, useState } from "react";
import { API } from "../api/client";
import type { McpEvent, RunState } from "../types";

export function useRunStream(epoch: number) {
  const [events, setEvents] = useState<McpEvent[]>([]);
  const [state, setState] = useState<RunState | null>(null);

  useEffect(() => {
    setEvents([]);
    const es = new EventSource(`${API}/stream`);
    es.addEventListener("mcp_event", (e) => {
      const ev: McpEvent = JSON.parse((e as MessageEvent).data);
      setEvents((prev) => (prev.length && prev[prev.length - 1].seq >= ev.seq ? prev : [...prev, ev]));
    });
    es.addEventListener("state", (e) => setState(JSON.parse((e as MessageEvent).data)));
    return () => es.close();
  }, [epoch]);

  return { events, state, setState };
}
```

```ts
import type { McpEvent } from "../../types";

export type NodeId = "host" | "llm" | "client" | "transport" | "server" | "tool" | "result";
export type EdgeId = "host-llm" | "host-client" | "client-transport" | "transport-server" | "server-tool" | "host-result";
export type Visual = "idle" | "active" | "done" | "error";

export const NODE_DEFS: { id: NodeId; label: string; x: number; y: number }[] = [
  { id: "llm", label: "Simulated LLM", x: 0, y: 0 },
  { id: "host", label: "MCP Host", x: 0, y: 150 },
  { id: "result", label: "Result Processing", x: 0, y: 300 },
  { id: "client", label: "MCP Client", x: 260, y: 150 },
  { id: "transport", label: "Transport (stdio)", x: 520, y: 150 },
  { id: "server", label: "MCP Server", x: 780, y: 150 },
  { id: "tool", label: "Tool Handler", x: 780, y: 300 },
];
export const EDGE_DEFS: { id: EdgeId; source: NodeId; target: NodeId }[] = [
  { id: "host-llm", source: "host", target: "llm" },
  { id: "host-client", source: "host", target: "client" },
  { id: "client-transport", source: "client", target: "transport" },
  { id: "transport-server", source: "transport", target: "server" },
  { id: "server-tool", source: "server", target: "tool" },
  { id: "host-result", source: "host", target: "result" },
];

type Touch = { nodes: NodeId[]; edges: { id: EdgeId; forward: boolean }[] };

export function touches(e: McpEvent): Touch {
  const nodes: NodeId[] = [];
  const edges: Touch["edges"] = [];
  switch (e.component) {
    case "user": nodes.push("host"); break;
    case "llm":
      nodes.push("llm"); edges.push({ id: "host-llm", forward: e.direction === "request" }); break;
    case "host":
      nodes.push("host");
      if (e.operation === "dispatch_to_client" || e.operation === "request_connect" || e.operation === "request_discovery")
        edges.push({ id: "host-client", forward: true });
      if (e.operation === "receive_result") edges.push({ id: "host-client", forward: false });
      if (e.operation === "supply_tools_to_llm") edges.push({ id: "host-llm", forward: true });
      if (e.operation === "final_response" || e.operation === "run_complete") { nodes.push("result"); edges.push({ id: "host-result", forward: true }); }
      break;
    case "client": nodes.push("client"); break;
    case "transport":
      nodes.push("transport");
      if (e.direction === "response") { edges.push({ id: "transport-server", forward: false }, { id: "client-transport", forward: false }); }
      else { edges.push({ id: "client-transport", forward: true }, { id: "transport-server", forward: true }); }
      break;
    case "server": nodes.push("server"); break;
    case "tool": nodes.push("tool"); edges.push({ id: "server-tool", forward: e.status === "started" }); break;
  }
  return { nodes, edges };
}

export interface FlowState {
  nodes: Record<NodeId, { visual: Visual; label: string }>;
  edges: Record<EdgeId, { visual: Visual; label: string }>;
  current: McpEvent | null;
}

export function deriveFlow(events: McpEvent[]): FlowState {
  const nodes = Object.fromEntries(NODE_DEFS.map((n) => [n.id, { visual: "idle" as Visual, label: "" }])) as FlowState["nodes"];
  const edges = Object.fromEntries(EDGE_DEFS.map((d) => [d.id, { visual: "idle" as Visual, label: "" }])) as FlowState["edges"];
  const last = events[events.length - 1] ?? null;
  for (const e of events) {
    const t = touches(e);
    const visual: Visual = e.status === "failed" ? "error" : e === last && e.status !== "completed" ? "active" : "done";
    const isLast = e === last;
    for (const n of t.nodes) nodes[n] = { visual: isLast && visual !== "error" ? "active" : visual, label: e.operation };
    for (const ed of t.edges) {
      edges[ed.id] = {
        visual: isLast && visual !== "error" ? "active" : visual,
        label: `${ed.forward ? "→" : "←"} ${e.method ?? e.operation}`,
      };
    }
  }
  if (last?.operation === "run_complete") {
    for (const id of Object.keys(nodes) as NodeId[]) if (nodes[id].visual === "active") nodes[id].visual = "done";
    for (const id of Object.keys(edges) as EdgeId[]) if (edges[id].visual === "active") edges[id].visual = "done";
    nodes.result = { visual: last.status === "failed" ? "error" : "done", label: last.status === "failed" ? "run failed" : "complete" };
  }
  return { nodes, edges, current: last };
}
```

```tsx
  const discoveries = events.filter((e) => e.operation === "list_tools" && e.status === "completed").length;
  useEffect(() => { endpoints.tools().then(setTools).catch(() => setTools([])); }, [discoveries, epoch]);

  const act = useCallback(async (fn: () => Promise<unknown>) => {
    try { setError(""); await fn(); } catch (e) { setError(String(e)); }
  }, []);

  const resubscribe = () => { setSelectedEventId(null); setInspectTool(null); setTools([]); setEpoch((n) => n + 1); };
  const selected = useMemo(() => events.find((e) => e.id === selectedEventId) ?? null, [events, selectedEventId]);
  const flowEvents = useMemo(() => {
    if (!selected) return events;
    return events.slice(0, events.findIndex((e) => e.id === selected.id) + 1);
  }, [events, selected]);
  const busy = state?.status === "running";

  return (
    <div className="app">
      <header><b>MCP Lab</b> <span className="muted">real MCP (mcp 2.3.0, spec 2026-07-28) · simulated LLM · playback delay is visual only</span></header>
      <ControlsBar state={state} busy={busy} delay={delay} stepMode={stepMode} onStepMode={setStepMode}
        onConnect={(m) => act(() => endpoints.connect(m))} onDiscover={() => act(endpoints.discover)}
        onPause={() => act(async () => setState(await endpoints.control("pause")))}
        onResume={() => act(async () => setState(await endpoints.control("resume")))}
        onStep={() => act(async () => setState(await endpoints.control("step")))}
        onDelay={(ms) => { setDelay(ms); act(() => endpoints.playback(ms)); }}
        onReset={() => act(async () => { await endpoints.reset(); resubscribe(); })} />
      {error && <div className="error">{error}</div>}
      <main>
        <aside>
          <h3>Scenarios</h3>
          <ScenarioPanel scenarios={scenarios} selected={scenarioId} onSelect={setScenarioId} events={events}
            onRun={() => scenarioId && act(async () => { await endpoints.runScenario(scenarioId, delay, stepMode); resubscribe(); })} />
          <h3>Tool catalog <span className="muted">(from tools/list)</span></h3>
          <ToolCatalog tools={tools} onInspect={(t) => { setInspectTool(t); setRight("inspector"); }}
            onInvoke={(n, a) => act(() => endpoints.callTool(n, a))} />
        </aside>
        <section>
          <FlowGraph events={flowEvents} onSelectComponent={(c) => { setComponent(c); setRight("components"); }} />
          <h3>Execution timeline</h3>
          <Timeline events={events} selectedId={selectedEventId} onSelect={(id) => { setSelectedEventId(id); setRight("inspector"); }} />
        </section>
        <aside>
          <div className="tabs"><button className={right === "inspector" ? "on" : ""} onClick={() => setRight("inspector")}>JSON inspector</button>
            <button className={right === "components" ? "on" : ""} onClick={() => setRight("components")}>Components</button></div>
          {right === "inspector" ? <JsonInspector event={selected} tool={inspectTool} />
            : <ComponentInspector events={events} selected={component} onSelect={setComponent} />}
        </aside>
      </main>
    </div>
  );
}
```
